# محمد للموبايل v2
واجهة متجر مائية فخمة من الصفر.
المزايا: الأقسام المطلوبة، سلة، طلب واتساب تلقائي، واتساب مباشر، إنستغرام، شعار يعيد للرئيسية، عنوان المتجر، وBackend بأساسيات أمنية.
التشغيل: انسخ .env.example إلى .env ثم npm install ثم npm start.
رقم واتساب يجب إدخاله في .env بصيغة دولية بدون +.
لا يوجد ضمان 100% ضد الثغرات؛ النشر الحقيقي يحتاج HTTPS/WAF وتحديثات ومراقبة ونسخ احتياطية.
